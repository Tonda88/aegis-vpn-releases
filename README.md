# Aegis VPN 1.3.2 для Android

Личное Android-приложение для защищённого подключения через собственные VPN-серверы.
Поддерживает **VLESS**, **Shadowsocks** и **WireGuard**, импорт ключей/конфигов (QR, буфер, файл, ссылка-подписка), несколько серверов, раздельное туннелирование, автоподключение/отключение по выбранным приложениям, плитку быстрого подключения в шторке и встроенную проверку обновлений.

Сборка **release**, подписана релизным ключом (не debug). Предназначена для установки вручную (sideload), не для Google Play.

## 1. Какой APK выбрать

В папке `APK` лежат сборки:

| Файл | Для кого |
|---|---|
| `AegisVPN-1.3.3-arm64-v8a.apk` | **Основной вариант.** Большинство современных телефонов/планшетов (64-бит ARM). |
| `AegisVPN-1.3.3-armeabi-v7a.apk` | Старые/бюджетные 32-битные устройства. |

Если не уверены — пробуйте **arm64-v8a**.

Минимальная версия Android — **7.0 (API 24)**, целевая — Android 14.

## 2. Установка

1. Скопируйте APK на телефон (USB, мессенджер, облако и т.д.).
2. Откройте APK в файловом менеджере.
3. При необходимости разрешите установку из неизвестного источника для приложения, из которого открываете файл (Android 8+).
4. Установите. Play Protect может предупредить о sideload-приложении — это ожидаемо.
5. При первом запуске выдайте запрошенные разрешения (уведомления, VPN-доступ и т.д.).

При обновлении поверх предыдущей версии подпись должна совпадать — используется тот же release-ключ.

---

## 3. Быстрый старт

1. Откройте вкладку **«Серверы»**.
2. Нажмите **«Добавить ключ»** или выберите способ импорта:
   - **QR-код** — сканирование ключа/ссылки;
   - **Файл** — `.conf` (WireGuard) или текстовый файл с ключами;
   - вставка ключа/ссылки из буфера.
3. Поддерживаемые форматы: `vless://...`, `ss://...`, `wg://...`, WireGuard `.conf`, а также `https://...` ссылка-подписка.
4. Выберите сервер в списке и нажмите **«Подключить»** на главном экране.
5. При первом подключении Android попросит разрешение на создание VPN-соединения — подтвердите.

В папке `APK` также лежит `subscription-keys.txt` со снимком ключей подписки Chorus Connect (можно импортировать ссылку подписки).

---

## 4. Раздельное туннелирование и авто-подключение

Во вкладке **«Приложения»**:
- **Раздельный туннель:** включить VPN только для выбранных приложений или, наоборот, для всех кроме выбранных.
- **Автоподключение/автоотключение по приложениям:** VPN включается при переходе в выбранные приложения и отключается при выходе из них.

Для автоподключения по приложениям требуется разрешение **«Доступ к данным об использовании»** (Usage access / «Доступ к статистике использования») — приложение подскажет, как его выдать в настройках системы. На некоторых прошивках также нужно снять ограничения фоновой работы/экономии батареи для Aegis VPN.

---

## 5. Плитка в шторке (быстрые настройки)

- Добавьте плитку **«Aegis VPN»** через редактирование быстрых настроек шторки.
- Нажатие: подключить выбранный сервер / отключить VPN.
- Если VPN-разрешение ещё не выдано, плитка откроет приложение для подтверждения.

---

## 6. Kill switch

Системный kill switch настраивается в Android (не внутри приложения):
1. Настройки → Сеть и интернет → VPN (путь может отличаться на разных прошивках).
2. Выберите **Aegis VPN** (шестерёнка/параметры).
3. Включите **«Постоянная VPN»** и **«Блокировать соединения без VPN»** (если доступно).

Кнопка перехода в настройки VPN есть в разделе **«Настройки»** приложения.

---

## 7. Обновления

- Приложение проверяет наличие новой версии при запуске и по кнопке **«Настройки → Обновления → Проверить обновления»**.
- Источник: публичный репозиторий релизов https://github.com/Tonda88/aegis-vpn-releases (`latest.json`).
- Перед установкой проверяется SHA-256; при необходимости Android запросит разрешение на установку из этого приложения.
- Как публиковать релизы и обновлять `latest.json`: см. **`PUBLISHING.md`**.

## Технические заметки

- Ядро: **sing-box 1.14.4** (`libbox.aar`, GPLv3).
- Стек: Kotlin, Jetpack Compose, minSdk 24, targetSdk 34.
- Конфиги/настройки хранятся локально на устройстве; VPN-трафик идёт через выбранный сервер.
- Исходники и материалы сборки: папка `source/`. APK и файлы публикации: папка `APK/`, `latest.json`, `PUBLISHING.md`.
- Приложение предназначено для личного использования.
